# PUMANext prototype

Interactive front-end prototype for the PUMANext productivity and value-realization workflow.

## Included workflows

- My Productivity task queue
- Four-step Create Measure workflow
- Monthly forecast and actual values
- Controller review and four-eye approval
- Management portfolio
- Best-practice library

The prototype uses synthetic data and browser `localStorage`. Enterprise APIs, authentication, file uploads, and financial integrations are intentionally mocked.

## Project structure

```text
src/
  index.html                Application markup
  assets/css/               Base, brand, workflow, and accessibility styles
  assets/js/app.js          Routes, interactions, validation, and demo data
scripts/
  dev.mjs                   Dependency-free local web server
  check.mjs                 Repository and route checks
  build.mjs                 Copies deployable files into dist/
.github/workflows/ci.yml    GitHub validation workflow
vercel.json                 Vercel build and output settings
```

## Run locally

Requires Node.js 20 or newer.

```bash
npm run dev
```

Open <http://127.0.0.1:4175>.

## Validate and build

```bash
npm run check
npm run build
```

The deployable static site is generated in `dist/`.

## Add to GitHub

Create an empty GitHub repository, then run from this folder:

```bash
git init
git add .
git commit -m "Add PUMANext prototype"
git branch -M main
git remote add origin https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY.git
git push -u origin main
```

## Deploy to Vercel

1. In Vercel, choose **Add New → Project**.
2. Import the GitHub repository.
3. Use **Other** as the framework preset.
4. Keep the build command as `npm run build`.
5. Keep the output directory as `dist`.
6. Deploy.

No environment variables are required for this prototype. Vercel will create preview deployments for branches and pull requests, and production deployments from the configured production branch.

## Editing guidance

- Update page structure in `src/index.html`.
- Update interactions and synthetic data in `src/assets/js/app.js`.
- Keep shared visual rules in `styles.css`, PUMANext branding in `brand.css`, the Create Measure workflow in `wizard.css`, and inclusive-design rules in `accessibility.css`.
- Do not edit `dist/` directly; it is generated by `npm run build`.
